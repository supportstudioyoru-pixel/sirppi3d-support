Sirppi3D Support

Decimation app for Mac - make heavy 3D data light

日本語

Sirppi3D is a Mac app that reduces the polygon count of heavy 3D data (decimation). Its main purpose is to bring data down to a size that opens in Kuu3D, the 3D viewer for iPhone and iPad. It is free, with no restrictions.

Supported formats
STLOBJPLYOFFglTFGLBUSD / USDA / USDC / USDZABCDAE

Export: STL / OBJ / GLB / PLY  |  Requires macOS 13 or later

Frequently asked questions
Basics
How do I use it?

Drop a 3D file onto the window (or choose File ▸ Open, ⌘O), set the target triangle count, and press "Export". The result is saved next to the original file (or in the folder chosen under "Output folder"). The original file is never modified.

What is "Match Kuu3D safe size"?

A button that sets the size that opens safely in Kuu3D (80 MB as STL, about 1.6 million triangles). The orange marker on the slider shows that position. Data that is larger is automatically reduced to this size when opened.

Can I compare with the original?

Hold the Space key to show the original data. You can also use the "Show original" checkbox.

How do I move around the model?

Scroll the mouse wheel (or pinch on a trackpad) to zoom, right-drag to rotate, and left-drag to pan. For data whose Z axis points up, turn on "Z-up" to see it in the right orientation.

Opening and exporting
A format cannot be opened.

ZTL, FBX, Blend and 3MF are not supported. Export from the original app as OBJ, PLY, GLB or USDZ first. Point clouds (PLY without faces) are not supported either.

What happens to textures and colors?

UVs and textures are discarded by decimation (only the shape is kept). Vertex colors are kept only when you export as PLY. They are not used for the on-screen display.

Which output format should I choose?

For Kuu3D, STL is recommended because it opens quickly (OBJ opens slowly in Kuu3D). Choose PLY if you want to keep vertex colors.

The size (scale) is off.

STL has no units, and Kuu3D reads the values as millimeters. Choose the unit of the source data (mm / cm / m / inch) under "Source unit" and it is converted to mm when saving.

How are files named?

By default the triangle count is added to the end (e.g. model_1500k.stl). Under "File name suffix" you can choose _decimated, your own text, or none. If a file with the same name exists, a number is added instead of overwriting it.

Decimation
The result does not reach the target triangle count.

If "Shape protection" under Advanced is on, processing stops before the shape error becomes too large, so the target may not be reached. Turn it off to reach the target.

It says "No decimation needed".

This is shown when the target is not below the original triangle count. In that case only the format is converted.

Can I stop a running job?

Press "Cancel" during processing. Writing stops and the partial file is removed.

Privacy and price
Does it cost anything?

No. It is free, with no restrictions.

Is my data sent anywhere?

No. The app makes no network connections and your files never leave your Mac. No personal data is collected. See the Privacy Policy for details.
